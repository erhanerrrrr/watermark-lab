# 几何恢复的边界填充压力诊断结果

日期：2026-09-05。该实验检查 AM-WAM 的几何恢复是否依赖人工旋转留下的中值色边角。
它使用已经出现在 formal-v1 和 robustness-v2 中的图像，因此属于**探索性机制诊断**，
不作为新的独立泛化验证，也不用于回调原有算法参数。

## 1. 为什么需要这项诊断

原实现 `geometry_border_evidence()` 比较角落和中心与全图中值颜色接近的像素比例。
证据低于 0.02 时，几何解码器直接跳过所有校正候选。原攻击协议的旋转和透视恰好采用
同一种中值颜色填充。改变旋转角度仍保留该填充方式，能够检验角度外推，却不足以
证明同步触发机制能够适应其他边界条件。

因此先冻结 `configs/border_stress_v1.yaml`，再运行下列对照：

| 维度 | 预先固定的选择 |
|---|---|
| 图像 | 四个 formal-v1 test manifest 按冻结顺序各取前 10 张，共 40 张 |
| 消息 | 32 bit；种子 20260905，按数据集和图像 ID 派生；模型间同图同消息 |
| 旋转 | −12.7°、+8.3°、+12.7° |
| 边界 | median、black、reflect、crop_resize |
| 模型 | 原 WAM 与原 AM-WAM，沿用正式强度和 M4 参数 |
| 额外对照 | 对每个 AM-WAM 嵌入后的攻击图，额外调用原始 WAM 解码器 |
| 规模 | 40 图 × 3 角度 × 4 边界 × 2 模型 = 960 条记录 |
| 统计 | 每张图先对 3 个角度平均，再对 40 个图像单元做 2,000 次配对 Bootstrap |

median 与原旋转攻击逐像素一致；black 只改变填充颜色；reflect 从原图反射扩展后
围绕同一中心旋转。单元测试验证三者共享旋转内部区域的采样结果。
crop_resize 先旋转，再裁出保留原宽高比的内接中心矩形，最后恢复原尺寸；它同时改变
视野和尺度，因此必须与单纯填充变化分别解释。reflect 还会在边界外复制原图内容，
本实验并不把它视为自然相机成像的完整模拟。

额外的同嵌入 identity 对照保持嵌入图、消息、攻击像素完全相同，仅去掉几何同步，
使同步收益不再与逐图质量反馈的收益混合。

## 2. 完整结果

已完成全部 **960 / 960 条**，40 个图像单元，每种边界每个模型 120 条记录；
结果键无重复且运行指纹一致。逐图推理与检查点写入累计约 664 秒。

下表前三列均为完整消息恢复率。“同嵌入 identity”使用 AM-WAM 的嵌入图，
关闭几何同步；同步净收益是 AM-WAM 减该对照，单位为百分点。

| 边界条件 | WAM | AM-WAM | 同嵌入 identity | 同步净收益（95% CI） | AM 跳过搜索 |
|---|---:|---:|---:|---:|---:|
| 中值填充 median | 21.67% | **83.33%** | 23.33% | **+60.00 [50.00, 69.17]** | 0.00% |
| 黑色填充 black | 14.17% | **16.67%** | 15.00% | +1.67 [0.00, 4.17] | **95.83%** |
| 反射填充 reflect | 11.67% | **33.33%** | 13.33% | +20.00 [11.67, 29.19] | 69.17% |
| 裁边后恢复尺寸 crop_resize | 1.67% | **12.50%** | 2.50% | +10.00 [3.33, 17.50] | 79.17% |

Bit Accuracy 与解码成本进一步表明，该变化不限于整串消息的苛刻判定：

| 边界条件 | WAM Bit Accuracy | AM-WAM Bit Accuracy | WAM 解码 | AM-WAM 解码 |
|---|---:|---:|---:|---:|
| median | 81.22% | 98.59% | 43.80 ms | 993.03 ms |
| black | 77.55% | 78.72% | 41.07 ms | 634.73 ms |
| reflect | 77.84% | 84.90% | 62.02 ms | 745.17 ms |
| crop_resize | 74.09% | 79.11% | 44.33 ms | 702.32 ms |

最重要的诊断是：**相同旋转角度下，把中值填充改成黑色，AM-WAM 的完整恢复率从
83.33% 降到 16.67%，同时 95.83% 的样本跳过几何搜索。**同嵌入对照显示，中值条件的
同步净收益为 +60.00 个百分点，黑色条件仅 +1.67，区间触及零。
这支持“原同步触发机制依赖中值边界先验”的解释，但不能把全部性能下降都归因于门控：
原始 WAM 在边界变化后也变差，边界像素本身会影响提取器；裁边场景还涉及视野和尺度变化。

反射和裁边条件仍存在部分同步收益，因此也不能写成“离开中值填充后完全无效”。
这些结果细化了原 formal-v1 与 robustness-v2 的适用条件，并未推翻冻结协议内已观测的
提升。后续算法应优先研究不依赖固定填充颜色的触发规则，并在新的 calibration 数据上
同时控制几何恢复、负样本误报和候选计算量；开发完成后另建独立测试，不能继续在这
40 张已观察图像上调参后宣称完成泛化验证。

小型机器可读汇总保存在 `docs/evidence/border_stress_v1.json`，可随 Git 交接。
PNG/PDF 图位于 `results/border_stress_v1/figures/border_stress_recovery.*`。
图中同时呈现三个恢复对照、图像级置信区间和跳过搜索比例。
