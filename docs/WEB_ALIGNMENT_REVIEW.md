# 前端与当前研究版本的对齐检查

日期：2026-09-05。

后续已完成 [TrustMark 独立进程接入](TRUSTMARK_WORKER.md)，当前配置为六模型均可用。
下文保留修复目录同步时的五模型可运行状态，作为该轮检查记录。

## 问题与修复

用户截图显示五个模型、5/5 可运行；同一时刻 8001 服务的 `/api/models` 和
`/api/catalog` 均返回六个模型，其中 Budget-WAM 可运行、TrustMark-Q 当前不可运行。
检查发现，前端原先只在首次挂载时读取目录，单页应用切换页面不会重新读取目录。
已打开的页面因而可能保留服务更新前的模型列表及运行状态。

- 页面切换、窗口获得焦点、页面重新可见时同步目录；页面可见时每 30 秒复查。
- 合并同时发生的刷新请求；实验完成后的刷新会等待旧请求，再读取新记录。
- API 请求和响应禁用缓存；HTML 要求重新验证，使重新打开页面时读取当前构建。
- 模型库将 Budget-WAM 放在首位，从独立证据接口读取其 PSNR、恢复率和候选调用数，
  并提供六方法结果入口。各模型明确标注 formal-v1、geometry-v3 或管线自检。
- 首页新增 Budget-WAM 研究摘要；原最佳恢复率明确限定为 formal-v1。
- 数据集页明确计数、下载及校验覆盖 Debug / formal-v1；攻击页明确覆盖 formal-v1。
  两页均提供 geometry-v3 独立验证入口，尚未扩展为 geometry-v3 清单管理页面。
- 页面切换复位滚动位置，避免沿用上一页滚动量遮住标题；模型卡片统一正文与指标区布局。

## 验证

- Python Ruff、145 项完整测试、前端 ESLint、TypeScript/Vite 生产构建通过。
- 当前 8001 服务返回六个模型、五个可运行；HTML 为 `no-cache`，API 为 `no-store`。
- 使用真实接口响应作为夹具，在 JSDOM 中先加载五模型旧目录，再切换到当前六模型目录。
  验证页面导航无需重载即可更新 Budget-WAM 与 TrustMark-Q 状态；焦点、可见性及轮询
  会重新同步；服务断开与恢复能反映到连接状态。
- 六个页面的 DOM 行为检查通过，包括实验默认模型、不可用选项、首页独立结果、结果
  深链接、六方法表及跨数据集筛选。记录见
  [client-qa.json](../artifacts/web-alignment/client-qa.json)。
- 本轮未执行真实浏览器截图或窄屏布局验收；DOM 检查不等同于这些可视验收。
- geometry-v3 的 16 个冻结依赖摘要全部匹配；本轮没有更改算法、冻结协议或研究结果。
